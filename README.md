# What count telemetry can and cannot reveal about detector-control attacks on decoy-state QKD

Code, per-seed results and manuscript source for a finite-key, drift-aware benchmark of intrusion detection on the count telemetry of decoy-state BB84.

- `code/`: simulator, finite-key bounds (Lim et al. 2014), detectors, experiment and table/figure scripts, unit tests. See `code/README.md` for the run order.
- `results/`: one JSON per seed (`seed_10.json` ... `seed_49.json`), `sensitivity.json`, `exploratory_dcs_p.json`, `exploratory_dcs_f.json`, `exploratory_stress.json`, aggregated `numbers.json`; development runs in `results/dev/`.
- `manuscript/`: LaTeX source; every number in the text comes from `numbers.tex`, generated by `code/make_tables.py`.

Main run: 40 held-out seeds, about 90 s per seed per core. Licence: MIT.
