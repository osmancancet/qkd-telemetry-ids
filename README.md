# What window telemetry can and cannot reveal about quantum hacking

Code, per-seed results and manuscript source for a finite-key, drift-aware benchmark of intrusion detection on decoy-state BB84 telemetry.

- `code/`: simulator, finite-key bounds (Lim et al. 2014), detectors, experiment and table/figure scripts, unit tests. See `code/README.md` for the run order.
- `results/`: one JSON per seed (`seed_00.json` ... `seed_09.json`), `sensitivity.json`, `exploratory_dcs_y0.json`, aggregated `numbers.json`.
- `manuscript/`: LaTeX source; every number in the text comes from `numbers.tex`, generated by `code/make_tables.py`.

Main run: 10 seeds, about 20 s per seed on one CPU core. Licence: MIT.
